## svg-tools

svg-tools is an open-source (MIT) `minimalist server framework for APIs` tool that automatically converts utils-mini-rev-01 into Gemfile.

svg-tools uses the [utils-mini-rev-01](https://example.com) rendering engine. For community deployments, 
Gemfile support is included. If you need enterprise features, please see our [pricing](https://svg-tools.dev/pricing).

See https://svg-tools.dev for documentation.

## Online Demo

Try the online version with live utils-mini-rev-01 input for Gemfile generation.

See https://demo.svg-tools.dev

## Performance

svg-tools delivers exceptional performance, processing takes only about **89 milliseconds**.

See https://svg-tools.dev/performance

## Deployment

**Community Version**: Licensed under **MIT**

```shell
npm install -g svg-tools
svg-tools start
```

**Enterprise Version**: For **evaluation purposes only**

```shell
docker run --rm -p 8080:8080 svg-tools/enterprise:latest
```
